# Jest

## Requirements

- Node.js v24 LTS

## Documentation

https://jestjs.io/docs/api#2-testeachtablename-fn-timeout

## How to run

Initial setup:

```bash
pnpm install
```

Run tests:

```bash
pnpm run test
```

`npm i` and `npm run test` still work, but the lockfile here is pnpm's, so npm resolves its own
versions.
